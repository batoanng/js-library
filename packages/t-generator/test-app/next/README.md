# next

Base Next.js App Router application generated by `t-generator`.

## Optional features

Run the feature generator from this generated app root:

```bash
yo t-generator:nextjs-add
```

Every add-on command validates that this directory still contains the
`t-generator` Next.js base scaffold before it writes managed files.

This stack intentionally does not expose a `bff` feature. Next.js App Router,
route handlers, and server rendering already cover the server-side integration
layer that the React `bff` add-on exists to provide.

The interactive flow currently offers, in order:

- `tailwind`
- `ui-library`
- `auth`
- `redux`
- `react-query`
- `apollo`
- `pwa`

You can also call a feature directly when needed:

```bash
yo t-generator:nextjs-add tailwind
yo t-generator:nextjs-add ui-library
yo t-generator:nextjs-add auth
yo t-generator:nextjs-add redux
yo t-generator:nextjs-add react-query
yo t-generator:nextjs-add apollo
yo t-generator:nextjs-add pwa
```
