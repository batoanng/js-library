<Source language="ts" code={`import { FileUpload } from "@batoanng/mui-components";`} />

## How to use this component

This component gives the consumer a way to upload and send files to a server.
The sending to the server is entirely up to the consumer, this component simply acts on the functions that are passed in.

You can embed this component in a form but if you want to use it that way you should be using the HookForm version of this component.
Which can be found in the `hook-form-adapters` package under `FormFileUpload`. Under the hood it uses this component with the flag `inForm`.
